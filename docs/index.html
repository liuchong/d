Quick Start

常用场景一句话启动

不划分“开发模式”与“生产模式”，同一套引擎兼顾本地文档预览、静态站点托管与 HTTP 协议语义调试。

场景示例 
# 启动当前目录的文档与代码服务
d -r . -p 8080

# 浏览器访问 Markdown / 源码即得白底阅读页，裸路径自动规范目录尾斜杠
# http://localhost:8080/README.md
# http://localhost:8080/docs/guide.md

Markdown 完整支持 GFM（表格、复选框、脚注、中英文锚点）、嵌入式 HTML 透传以及纯 Rust 浅色代码高亮。

Capabilities

为什么重构后的 d 更简单、更快、更独立

从 L0 微内核、L1 传输监管、L2 自建 HTTP/1.1 引擎到 L4 纯白底内容展示层，全部保持清晰静态契约与可控实现。

L0 Microkernel

零依赖插件微内核

crates/frame 纯 std 实现作用域服务、纤程依赖级联重建、结构化异步效应 LIFO 回滚、四类强类型事件与配置预检。

HTTP/1.1 Engine

自建 HTTP/1.1 与无锁路由

自建解析边界（400/413/414/431/505）、streaming: true 零缓冲 chunked 输出与 ArcSwap 风格原子快照路由器。

Markdown & Highlight

纯 Rust GFM + 嵌入式 HTML

服务端直接完成表格对齐、复选框、脚注、中英文唯一锚点、原生 HTML 标签透传与多语言词法高亮，彻底零外网脚本。

White Minimal UI

统一极简白色纸面体系

全站采用 #ffffff 画布、#f6f8fa 辅底、#e5e7eb 细线与 #0969da 强调蓝，无深色杂糅、无彩色胶囊、无 emoji 堆砌。

Streaming Filter

流式感知压缩与可选 CORS

按 br > gzip > deflate 协商；自动豁免 SSE、206、304、HEAD、已压缩音视频字体及小体积实体；CORS 默认关闭。

Security & RFC 9110

沙箱安全、Range 与 304

路径穿越与符号链接逃逸 canonicalize 校验、隐藏点文件默认隔离、精确字节切片 206/416、ETag/IMS 304 与 RFC 5987 下载。

Conflict-Free Routing

无冲突内容与媒体路由契约

媒体/静态脚本裸路径永远直出原始字节流；文档与代码默认渲染白底阅读页，按需通过 ?view= 或 ?listing=true 切换视图。

Architecture

五层单向依赖架构与 32 个 Workspace 包

上层只依赖下层契约包（contracts/*），实现之间零横向直接耦合，由 d（17 插件全栈网关/文件/开发套件）与 d-minimal（轻量静态版）按声明式 Loader 装配并支持可选 d-mcp 实时控制。

了解 frame 微内核设计

第 0 层 · frame 插件微内核

包含包（Crates） crates/frame（零外部依赖，纯 std）
依赖约束 仅依赖 Rust 标准库 std

提供 ScopedService、Context、Scope 作用域隔离与同域继承、可选依赖 Deps、Fiber 父子树状态机、EffectScope 逆序回滚与并发清理、内置锁外生命周期事件、嵌套组增量 Loader 与 Inspect。

Roadmap

演进路线图

阶段 1 至阶段 5 已全部交付并通过 32 包架构门禁、端到端验收及独立干净重建。

阶段 1 · 零外部依赖插件微内核（crates/frame）

已完成 · F01–F16

纯 std 实现 ScopedService、父子 Fiber 树与同域继承、可选依赖与卸载快照、Context 元信息/拦截器、内置锁外事件与嵌套分组增量 Loader。

阶段 2 · 五层重构、契约升级、双装配体与 MCP / Skill 体系

已完成 · d / d-minimal / d-mcp

落地纯 Virtual Workspace、自建 HTTP/1.1 引擎、零手工包装 ScopedService 接线、可互换 doc-render-plain、可选纯 Rust d-mcp、skills/{d,d-dev} 与 xtask 治理工具。

阶段 3 · 纯内建 Markdown、词法高亮与极简白色界面

已完成 · 全栈闭环

交付零外部依赖 doc-render（含可选 sanitize_html）与 viewer-*，实现无冲突媒体/文档路由、全站纯白视觉规范与端到端 HTTP 验收闭环。

阶段 4 · 声明式配置热重载、治理扩展与开发套件

已完成 · -c / SIGHUP

交付纯 std -c/--config 与 SIGHUP 增量热重载（不中断无关 SSE/WS 长流）、三大纯 std 治理组件（ext-observability/ext-ratelimit/ext-auth）与 ext-dev-kit。

阶段 5 · 纯 Rust TLS、WebSocket / TCP 与通用反向代理

已完成 · GA01–GA28

交付 l4-tls（SNI/ALPN/原子热换证）、纯 Rust RFC 6455 proto-ws、proto-tcp 与 L7/L4 ext-proxy（Keep-Alive 池/LB/主被动健康检查/SSE 与 WS 隧道）。
