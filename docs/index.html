Quick Start

常用场景一句话启动

不划分“开发模式”与“生产模式”，同一套引擎兼顾本地文档预览、静态站点托管与 HTTP 协议语义调试。

场景示例 
# 启动当前目录的文档与代码服务
d -r . -p 8080

# 浏览器访问 Markdown / 源码即得白底阅读页，裸路径自动规范目录尾斜杠
# http://localhost:8080/README.md
# http://localhost:8080/docs/guide.md

Markdown 完整支持 GFM（表格、复选框、脚注、中英文锚点）、嵌入式 HTML 透传以及纯 Rust 浅色代码高亮。

Capabilities

为什么重构后的 d 更简单、更快、更独立

从 L0 微内核、L1 传输监管、L2 自建 HTTP/1.1 引擎到 L4 纯白底内容展示层，全部保持清晰静态契约与可控实现。

L0 Microkernel

零依赖插件微内核（d-frame）

纯 std 实现 ScopedService、作用域隔离与同域继承、纤程级联重建、结构化异步效应 LIFO 回滚、四类强类型事件与增量 Loader。

L1 Transport & TLS

多监听传输与纯 Rust TLS

d-l4-transport 提供 max_connections 限制与两阶段优雅排空；d-l4-tls 隔离 rustls，支持 SNI、ALPN 与运行期原子热换证不杀旧会话。

L2 Protocol Engines

HTTP/1.1 · 纯 Rust WS · 原生 TCP

d-proto-http 支持 :param/*rest、分块流式请求体、413 限额与 101 移交；d-proto-ws 仅依 tokio 实现纯 Rust RFC 6455；d-proto-tcp 承载四层字节流。

L3 Reverse Proxy

通用 L7/L4 反向代理（d-ext-proxy）

HTTP/1.1 Keep-Alive 连接池、RR/LC/WRR 均衡、主被动健康检查与熔断、RFC 7239 Forwarded、SSE 零缓冲穿透、WS 101 双向隧道与 TCP 透传。

L3 Governance

三大纯 std 零外依治理组件

d-ext-observability（JSON 访问日志 / /metrics / /healthz / /readyz）、d-ext-ratelimit（IP 令牌桶 429）与 d-ext-auth（常量时间 Bearer/Basic/CIDR 401/403）。

L3 Dev Workflow

内置开发提效套件（d-ext-dev-kit）

声明式静态与延迟 SSE Mock、零外链 Live Reload，以及纯白 #ffffff /_d/inspect（含 SSE/WS 时间线与请求一键重放）。

Markdown & Highlight

纯 Rust GFM + 严格白名单净化

d-doc-render 服务端完成表格对齐、脚注、中英文锚点、多语言词法高亮与可选 sanitize_html 严格白名单（标签/属性过滤 + URI 实体解码）。

White Minimal UI & Files

多挂载白底文件与流式压缩

d-app-files 与 d-viewer-* 支持 mount_prefix/host 多挂载、Range/ETag/304、RFC 5987 下载、#ffffff 零外链界面与 d-ext-compression/d-ext-cors。

Entries, Reload & MCP

-c / SIGHUP 无损重载与 d-mcp

d-cli / d-daemon 实现纯 std JSON 清单与 SIGHUP 预检拒载及无中断热更（不杀无关 SSE/WS）；可选 d-mcp 自发现 17 插件并配套 skills/{d,d-dev}。

Conflict-Free Routing

无冲突内容与媒体路由契约

媒体/静态脚本裸路径永远直出原始字节流；文档与代码默认渲染白底阅读页，按需通过 ?view= 或 ?listing=true 切换视图。

Architecture

五层单向依赖架构与 32 个 Workspace 包

上层只依赖下层契约包（crates/contracts/*），实现之间零横向直接耦合，由 d（17 插件全栈网关/文件/开发套件）与 d-minimal（轻量静态版）按声明式 Loader 装配（R-ARCH-9 强制 crates.io 仅发布单包 d，其余 31 个内部包一律 publish = false，由 xtask 校验 9 条架构规则）并支持可选 d-mcp 实时控制。

包含包（Crates） d-frame (crates/frame · 零外部依赖，纯 std)
依赖约束 仅依赖 Rust 标准库 std
