d / 使用指南

命令行、网关反代、路由契约与嵌入开发完整指南

一页查清 d v0.1.1 的全部开关、环境变量、-c / SIGHUP 声明式网关与开发工作流清单、?view= / ?listing= 路由规则、内建 GFM / 严格白名单净化，以及如何作为 Rust 库（d / d-*）装配运行。

Interactive CLI Builder

交互式命令与环境变量生成器

勾选或输入参数，实时生成可直接复制运行的 CLI 命令或等效 D_* 环境变量启动行。

d

命令行参数优先级始终高于环境变量；布尔型环境变量同时识别 1、true、yes、on（忽略大小写）。

CLI & ENV Reference

命令行选项与环境变量对照表

所有值选项均支持空格分隔（-p 3000）和等号连接（--port=3000）两种写法。

选项 环境变量 默认值 行为说明
-H, --host <HOST> D_HOST localhost 解析监听地址；对主机名解析优先选用 IPv4 地址。
-p, --port <PORT> D_PORT 8080 监听 TCP 端口（u16 合法端口）；非法端口直接报错退出。
-r, --root <PATH> D_ROOT . 根目录路径；启动时执行 canonicalize 校验是否存在与可访问。
-c, --config <PATH> D_CONFIG 未指定 声明式 JSON 插件清单；配合 kill -HUP 执行全量预检与无中断增量热重载。
-l, --log <LEVEL> RUST_LOG info 日志阈值：trace、debug、info、warn、error。
--hidden D_SHOW_HIDDEN 关闭 允许展示点文件并启用页面/URL ?hidden=true|false 切换。
--cors D_CORS 关闭 附加 Access-Control-Allow-Origin: *，预检 OPTIONS 返回 204。
--no-http D_NO_HTTP 关闭 仅在内存启动路由（不绑定 HTTP 端口），等待经 MCP 动态设置 proto-http.bind_addr。
--mcp-stdio / --mcp-http <ADDR> D_MCP_STDIO / D_MCP_HTTP 关闭 按需启用 stdio（日志切往 stderr）或独立 HTTP MCP 控制端点。
--mcp-path / --mcp-token / --mcp-read-only / --mcp-allow-shutdown D_MCP_PATH / D_MCP_TOKEN / D_MCP_READ_ONLY / D_MCP_ALLOW_SHUTDOWN /mcp / 无 / 关 / 关 配置 HTTP MCP 路径、Bearer 鉴权令牌、只读保护与远程优雅关停授权。
-h, --help / -V, --version — — 分别打印完整 CLI 帮助信息或当前版本号后以退出码 0 退出。
Gateway, Proxy & Hot Reload

声明式清单、网关治理与 SIGHUP 热重载

通过 d -c <PATH>（或 D_CONFIG）声明式装配 l4-transport、l4-tls、proto-{http,ws,tcp}、ext-proxy、三大纯 std 治理扩展（ext-{observability,ratelimit,auth}）、ext-dev-kit 与多挂载 app-files；运行期发送 kill -HUP 执行全量预检与无中断增量重载（不中断无关 SSE/WS 长流）。

生产网关 / 治理验证（gateway.json） 
# 启动声明式网关清单（观测/限流/鉴权/文件服务 + sanitize_html）
d -c examples/gateway/gateway.json

# 验证探针与 OpenMetrics 指标
curl -i http://127.0.0.1:8080/healthz
curl -i http://127.0.0.1:8080/readyz
curl -s http://127.0.0.1:8080/metrics | head -n 20

# 发送 SIGHUP 安全增量热重载（错配整体拒载）
kill -HUP <d_pid>
开发提效工作流（dev.json / ext-dev-kit） 
# 启动内置 Mock + Live Reload + 白底检视器
d -c examples/gateway/dev.json

# 静态 JSON Mock 与零缓冲 SSE Mock
curl -i http://127.0.0.1:8080/mock/user
curl -N http://127.0.0.1:8080/mock/sse

# 打开纯白零外链时间线与请求重放 UI
# http://127.0.0.1:8080/_d/inspect
MCP & Self-Evolving Skills

可选 MCP 动态控制面与随版本演进 Skill

通过 d-mcp（12 项控制工具 + 4 项只读资源）可在不停服状态下调整插件配置、开关 CORS/隐藏文件、切换根目录、重绑端口与调整日志级别；仓库自带 skills/d 与 skills/d-dev，由各组件 Plugin::schema() 自动同步演进。完整说明见 docs/mcp.md。

Routing & Rendering

无冲突路由、内建 Markdown 与语言高亮

所有展示页面均由服务端纯 Rust 生成且零外链；下表给出各文件类型与查询参数的完整行为组合。

资源 / 查询参数 返回行为 典型用途
/dir（无尾斜杠） 301 Moved Permanently 跳转 /dir/（保留 ?query） 保证 Markdown ./img.svg 与静态页面相对路径基准正确
/dir/ 优先直出沙箱内 index.html；否则输出极简白底目录列表 静态网站托管与文件浏览；?listing=true 可绕过首页
?sort=name|size|time|type&order=desc 对目录列表排序（目录始终排在文件之前） 按修改时间或体积快速定位目标文件
?view=raw 直接输出文件原始字节与精准 MIME（支持 Range/ETag） 读取 Markdown 源码、配置文件或验证原始内容
?view=preview 输出纯白底渲染/高亮 HTML 正文，省略顶部导航条 嵌入其他页面 <iframe> 或专注纯阅读排版
?view=viewer 为图片、音视频、脚本生成白底查看页（内嵌裸路径媒体标签） 浏览器直接看图与拖动音视频进度，而不破坏裸路径直链
?view=download 返回 Content-Disposition: attachment; filename*=UTF-8''... 遵循 RFC 5987 下载中英文与特殊字符文件名
GFM & Anchors

完整文档规范

标题自动生成去重中英文锚点；支持对齐表格、任务列表复选框、删除线、脚注 [^1]、自动链接与行内/围栏代码。

Embedded HTML

原生 HTML 与严格白名单净化

默认保留块级与行内 HTML（<details>、<figure>、<img>、<table>）；面向公网开启 sanitize_html: true 可启用严格标签/属性白名单、引号感知扫描与 URI 实体解码，同时保留 MarkdownOptions::sanitizer 钩子。

Rust Library API

作为 Rust 库或无端口测试运行时嵌入

所有层都可以通过 d::build_runtime、d::create_app_with_options 或 d::start_with_options 组合使用。

crates/assemblies/d/src/lib.rs 公开入口示例 
use d::{Options, create_app_with_options, start_with_options};
use d_http_api::{HttpRequest, Method};
use std::net::SocketAddr;

pub async fn run_server() -> Result<(), Box<dyn std::error::Error>> {
    let addr: SocketAddr = "127.0.0.1:8080".parse()?;
    start_with_options(
        &addr,
        "./public",
        Options {
            allow_hidden: false,
            cors: true,
        },
    )
    .await;
    Ok(())
}

pub async fn dispatch_in_memory() -> Result<(), Box<dyn std::error::Error>> {
    let app = create_app_with_options(
        "./examples/docs",
        Options {
            allow_hidden: false,
            cors: false,
        },
    )
    .await;

    let resp = app
        .dispatch(HttpRequest::new(Method::Get, "/guide.md?view=preview"))
        .await;
    assert_eq!(resp.status.as_u16(), 200);
    let _html = resp.body.into_bytes().await?;

    app.dispose().await?;
    Ok(())
}
